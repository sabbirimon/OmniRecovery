Automation
Use local JSON commands from an AI agent or a script.

        
Custom search and verification
omnirecovery-cli catalog /path/to/export --query DCIM
omnirecovery-cli verify /path/to/capture.dd
omnirecovery-cli scan /path/to/capture.dd --storage memory-card
On macOS, the CLI is inside the app at Contents/MacOS/omnirecovery-cli. On Windows, use the separate CLI executable. Give the agent an explicit local source. Search matches names and relative paths.

        
Export destinations
Choose a local folder, mounted NAS, or synced folder for reports and archives. Verified recovery and image cloning use a separate directly attached physical drive on macOS.
